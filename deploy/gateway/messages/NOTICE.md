# Standard ROS 2 message definitions

These five unmodified message definitions are redistributed under Apache License 2.0.
Package versions, source paths, and SHA-256 hashes are in SOURCE.json. Original
comments and package.xml author/license metadata are preserved. The full license is
LICENSE.Apache-2.0. Sources: https://github.com/ros2/common_interfaces and
https://github.com/ros2/rcl_interfaces (ROS 2 Jazzy). No ROS implementation code is copied.

The gateway loads these definitions locally so the pinned SDK does not need to clone
message repositories or change Git configuration while running.
