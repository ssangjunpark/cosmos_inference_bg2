## Starting later

1. On PRO 6000, start the real model service using `scripts/cosmos3.py serve` as in
   the three-machine runbook, choosing an available GPU.
2. In another terminal on PRO 6000, open the tunnel:

   ```bash
   ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=15 -o ServerAliveCountMax=3 \
     -R 127.0.0.1:18008:127.0.0.1:8008 3sp5090
   ```

3. After camera/profile verification and FFW readiness, on the 5090:

   ```bash
   cd ~/cosmos_bg2_gateway
   docker compose up --no-build
   ```

FFW deployment and execution are separate work and have not been performed.
